AlgoRHYTHM

About the Project

AlgoRHYTHM is a rhythm game, that challenges your sense of rhythm by having you perform actions, like hitting buttons or dancing, with precise timing to match a song.

Features

  • Dynamic note generation
  • Multiple difficulty levels
  • Accuracy scoring
  • Beat-matching system

Technologies Used

Python Pygame Canva Ibispaint

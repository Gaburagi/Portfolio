F1 + X

About the Project

F1 + X is a modern laundromat app designed to streamline the laundry experience. It provides users with a convenient way to manage their laundry needs, track orders, and schedule pickups/deliveries.

Features

  • Real-time order tracking
  • Schedule pickup and delivery
  • Multiple payment options
  • Service customization
